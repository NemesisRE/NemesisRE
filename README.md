### Projects

- [**kiosk-mode**](https://github.com/NemesisRE/kiosk-mode): hides the Home Assistant header and/or sidebar.
- [**dotfiles**](https://github.com/NemesisRE/dotfiles): same config, prompt, aliases and completions on Bash, Zsh, PowerShell, Fish and Nushell, across Linux, macOS and Windows.
- [**vscode-trilium-extension**](https://github.com/NemesisRE/vscode-trilium-extension): browse, search and edit Trilium Notes inside VS Code.
- [**famvacay**](https://github.com/NemesisRE/famvacay): self-hosted family vacation planner around school holidays, public holidays, weather and prices.
